# E-Portfolio

Project for creating a living resume and showcasing of general HTTP CSS and JS knowledge 

*possibility of more languages/tools added in middle of creation is possible


Plan of having "living resume" format, it covers my about, my skills, my role, and highlights projects I have made.

Additionally, will be a form of showcasing the ONE project which will be a full stack app (will link to a seperately hosted website which has the app, rather than having 2 things in one)

Design philosophy will follow simplistic yet appealing design which clearly conveys structure and manages to show technical ability over being a simple design choice for everything done.

Includes things such as contact info, short bio, current role, linkedin, resume and the github

Level of design integration over just functionallity is debatable
